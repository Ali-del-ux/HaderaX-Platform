## 📑 النبذة المختصرة للمشروع (Project Abstract)

> **منصة الحاضرة للتعليم المستمر والتطوير التقني** هي بيئة تدريب رقمية هجينة تابعة لجامعة الحاضرة، تهدف إلى ردم الفجوة بين المناهج الأكاديمية النظرية ومتطلبات سوق العمل البرمجي والأمن السيبراني. 
>
> تتيح المنصة للجامعة إطلاق معسكرات ودورات تدريبية متخصصة تجمع بين المحاضرات الرقمية والورش العملية داخل المختبرات، وتتميز بنظام حضور لحظي مشفر بتقنية الـ **QR Code** لتوثيق الالتزام الفعلي للطلاب بالقاعات، مع معمارية برمجية محصنة وحوكمة صارمة للصلاحيات وفق أعلى معايير أمان الويب العالمية (**OWASP**).

---

## 💎 الركائز الوظيفية والتقنية للأكاديمية (Core Capabilities)

1. **التعليم الرقمي الهجين (Hybrid Digital Training):** إدارة مسارات برمجية ومعسكرات متخصصة تشمل محاضرات رقمية، مراجع هندسية، وورش عمل معملية موثقة.
2. **الحضور اللحظي المشفر بالـ QR Code:** جلسات حضور متغيرة ومحدثة ديناميكياً تمنع التلاعب وتتيح توثيقاً لحظياً لالتزام المتدربين داخل القاعات والمختبرات.
3. **حوكمة أمنية وصلاحيات دقيقة (OWASP RBAC Governance):** هيكلة إدارية تفصل بين المشرف العام، مشرف شؤون الطلاب، ومشرف المناهج لضمان سرية البيانات والنزاهة الأكاديمية.
4. **نظام تصميم عصري محايد (Obsidian Pro Minimalist):** واجهة مونوكرومية فائقة الراحة للعين تحقق أعلى درجات التباين المعتمدة دولياً (WCAG AAA)، وتبرز شعار القلعة الذهبي كعلامة التميز الحصرية للأكاديمية.

## ⚡ التشغيل السريع بأمر واحد (One-Click Setup)

لتشغيل المنصة فورياً على بيئتك المحلية:

### 🚀 الطريقة المباشرة (Windows):
انقر نقراً مزدوجاً على الملف:
```cmd
start.bat
```
> **يقوم الملف تلقائياً بالآتي:**
> 1. فحص توفر بيئة Node.js.
> 2. تنصيب مكتبات الباك إند (`npm install`) تلقائياً.
> 3. إنشاء وتهيئة ملف الإعدادات `.env`.
> 4. زراعة حسابات المشرفين والطلاب في قاعدة البيانات (`seedAdmin` & `importStudents`).
> 5. إطلاق الخادم على المنفذ 3000 وفتح المتصفح تلقائياً على `http://localhost:3000`.

## 🛠️ التنصيب والتشغيل اليدوي للمطورين (Manual Setup)

```bash
# 1. استنساخ المشروع
git clone https://github.com/Ali-del-ux/HaderaX-Platform.git
cd HaderaX-Platform

# 2. تنصيب الحزم
cd backend
npm install

# 3. إعداد الاتصال بقاعدة البيانات
cp .env.example .env

# 4. تهيئة الجداول وحسابات الأكاديمية
node scripts/seedAdmin.js
node scripts/importStudents.js

# 5. تشغيل الخادم
node server.js
```
الرابط المحلي: **`http://localhost:3000`**

## 🔐 معايير الحماية والأمان وفق OWASP (Security Standards)

1. **الحماية ضد حقن SQL (SQL Injection):** جميع استعلامات قواعد البيانات تعتمد Prepared Statements والتمرير المعلماتي بنسبة 100%.
2. **تحصين الجلسات ضد XSS و CSRF:** التوكن (JWT) مخزن حصرياً داخل `HttpOnly Secure Cookie` لمنع سرقته عبر أكواد JavaScript الضارة.
3. **حوكمة الصلاحيات (Granular RBAC):** حماية كل مسار إداري عبر وسيط تحقق مشدد قبل السماح بأي عملية.
4. **جدار حماية رفع الملفات (File Upload Firewall):** تقييد الأنواع المسموحة (MIME Types) وحظر كل الملفات التنفيذية بحد أقصى 50MB.
5. **تشفير كلمات المرور:** اعتماد خوارزمية **Bcrypt** بجولات تمليح آمنة لحماية كلمات المرور عند التخزين.
6. **سجل التدقيق والتتبع (Audit Logging):** تسجيل كل العمليات وعناوين IP والمحاولات المشبوهة عبر **Winston Logger**.
